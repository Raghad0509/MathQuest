# Project Idea and Scope
Arabic version: [../ar/02-project-idea.md](../ar/02-project-idea.md)

## Project Name
- MathQuest

## Core Idea
MathQuest is a mobile adventure game for children (age 7-12).

It is not a normal quiz app.

The player explores a treasure-map world.
To move forward, they must solve math puzzles at obstacles.

## Learning + Game Balance

- Game first: map, movement, obstacles, rewards
- Learning mechanic: math questions unlock progress

## Main Player Journey

1. Select profile
2. Open home/adventure map
3. Choose unlocked level
4. Face obstacles in sequence
5. Solve math puzzle to unlock obstacle
6. Complete level
7. Earn points/stars/achievements
8. View progress in statistics

## Current Worlds

- Forest of Numbers
- Bridge of Addition
- Cave of Multiplication
- Castle of Equations
- Treasure Island

## Obstacle Types

- bridge
- gate
- rock
- magical_door
- treasure_chest
- mini_boss (final obstacle per level)

## New Gameplay Features Added

- Hint system:
  - Player can request a hint in puzzle screen
  - Hint costs 5 points
  - One wrong option is removed

- Daily streak reward:
  - Completing level on consecutive days builds streak
  - Bonus points are granted on level completion

- Mini boss at end of each level:
  - Last obstacle is a mini boss
  - Requires more effort than normal obstacles

## Why This Project is Good for Student Demo

- Clear full-stack architecture (mobile + backend API)
- Real game flow, not only forms/screens
- Good separation of models, views, services, components
- Easy to explain design and future scalability
